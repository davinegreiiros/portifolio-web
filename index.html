03 / MÉTODO

Sonho de Criança

Sistema de aluguel de brinquedos por tempo: o monitor abre o posto no tablet, cronometra cada locação, recebe por Pix e fecha o caixa do turno; o dono acompanha tudo e recebe o relatório no WhatsApp.

// front · Flutter
  • Migração incremental de um AppState global para camadas Repository → Cubit → View, em 12 specs, sem quebrar o app no meio.
  • Pix QR Code, alarmes locais de fim de tempo, persistência SQLite e sessão de dispositivo.
  • Posto do monitor, fechamento de turno (esperado × contado) e trilha de lançamentos imutável.
// back · Next.js
  • API em Next.js + TypeScript + MongoDB: rotas finas, repositories por coleção, validação Zod.
  • Auth por operador com JWT + bcrypt, multi-tenant por aparelho registrado e painel do desenvolvedor com Server Actions.
  • Security review fechado: enumeração no login, condição de corrida e limite de corpo em stream chunked.
